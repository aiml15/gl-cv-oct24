## 🚀 Getting Started on Google Colab

Follow these steps to set up the project environment using Google Colab and Google Drive.

### Step 1: Prepare Your Notebook
1. Go to [Google Colab](https://google.com).
2. Create a new, empty Jupyter notebook.

### Step 2: Mount Google Drive
Run the following code block in your Colab notebook to connect your Google Drive:

```python
from google.colab import drive
drive.mount('/content/drive')
```

### Step 3: Clone the Repository
Navigate to your Drive's root folder and clone the project repository by running:

```bash
%cd /content/drive/MyDrive
!git clone -b main https://github.com/aiml15/gl-cv-oct24.git
```

### Step 4: Open the Project Notebook
1. Open your **Google Drive**.
2. Navigate to the cloned repository folder (`gl-cv-oct24`).
3. Right-click the notebook file you want to use and select **Open with** > **Google Colab**.
